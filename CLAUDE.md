# Tripoli: Open Source — notes for Claude

An interactive map of Tripoli under Gaddafi (1969–2011) for older relatives. A static Leaflet app in `public/`, served by one Cloudflare Worker (`worker/worker.js`, name `tripoli-atlas-ai`) behind a family password. Cloudflare Workers Builds redeploys on every push to `main`, so a broken file on `main` goes live. See `README.md` and `SETUP-AI.md` for setup and secrets (never commit secrets).

## Layout
- `public/` — the only folder ever served. `index.html`, `app.js` (map, drawers, filters, chat guide), `i18n.js` (Arabic strings), `unknown.js` / `unknown-art.js` (the **Intelligence** network view; it was called "The Unknown" before, so older notes may use that name).
- `public/data/` — the content:
  - `sites.js` — `ATLAS_SITES` (map pins) and `ATLAS_UNPLACED` (researched items with no published location). The main file research edits.
  - `unplaced.js` — `ATLAS_UNPLACED_MORE`, generated by `scripts/build-areas.py`. Do not hand-edit.
  - `areas.js` (172 areas, incl. `npic-*` military sites and `lb-`/`lm-`/`lh-` landmarks), `records.js`, `people.js`, `stories.js`, `links.js`, `overlays.js`, `quotes.js` (generated), `unknown.js` (generated).
- `worker/worker.js` — password gate, AI relay, tools for the chat guide.
- `scripts/` — data builders and collectors (Python and Node).
- `archive/` — source corpora used for research (CIA reading room, FBIS, JPRS, Wikipedia en/ar, country studies, gov). **Not served.** Search it before going to the web.

## Pin schema (`ATLAS_SITES`)
`id, layer, level, y0, y1, name, ar, lat, lon, r, period, relevance, text, sources[{t,u}]`
- Layers: `detention`, `security`, `military`, `airstrike`, `battle`, `massacre` (shown as "Killings & repression"), `power`, `landmark`.
- Levels: `documented`, `testimony`, `suspected`, `context`.
- `r` is the honest uncertainty radius in km.
- `sites.js` has helpers: `cia(id, title)` builds a CIA reading-room source; `SRC` is a dictionary of common sources.
- `ATLAS_UNPLACED` entries are `{ name, when, text, src }`; `src` can be one `{t,u}` or an array (the list shows "Source 1", "Source 2", …).

## Research rules (the family relies on this being honest)
- Every item needs a fetched source. Never invent coordinates, names, dates or numbers.
- Pin only when a source names a place in Tripoli; use an honest `r` and `level`. Otherwise add to `ATLAS_UNPLACED`.
- Killings, executions and deaths in custody go in layer `massacre`, never labelled as battles.
- Report unverified claims as such ("reported", "says"). Note where sources disagree.
- Check for duplicates in `sites.js` before adding. Items outside Tripoli (for example the Feb 1987 hangings in Benghazi) do not belong on the map.
- Many FBIS/JPRS "Tripoli" hits are Tripoli, Lebanon. Exclude them.
- Sources that worked: CIA reading-room copies of Washington Post and Times, FBIS and JPRS texts, Amnesty PDFs (MDE 19 series), tarikhi.org interviews, MERIP, Wikipedia. WebFetch only works for URLs surfaced by WebSearch or given in a message.

## Build and check
- `node --check public/app.js` and `node --check public/data/sites.js` after every edit.
- After changing `scripts/place_aliases.py`: `python3 scripts/build-unknown.py` (edges between two mapped nodes are dropped, so those nodes then leave the Intelligence view; that is expected).
- After research changes that affect quotes: `python3 scripts/build-quotes.py`.
- Local test: run `python3 -m http.server 8765` inside `public/`, then load `http://localhost:8765/index.html`. A Playwright script can drive it (cloud sandbox has Chromium at `/opt/pw-browsers/chromium`; Esri tile requests may be blocked there, which is harmless).

## UI behaviour worth knowing
- Layers drawer (`buildFilters` in `app.js`): Map style first, then What and When (year sliders plus era chips such as "Gaddafi years" and "All years"), then "Pick layers one by one". The old "How sure" filter is gone (`sure` is fixed to `'all'`). The separate "Time period" section is hidden. The timeline uses its own `timeRange`.
- Blue neighbourhood badges (`hoodMode`) appear only at zoom < 14, with no timeline range, year or story active, and more than 50 visible pins.

## Git etiquette
- Scheduled research tasks push to `main` on a timer. Always `git pull --rebase` before pushing, and keep unrelated work (for example USGS imagery tooling) in new files so it does not collide with `sites.js`.
- Commit messages end with the attribution lines the session gives you.

## Research schedule (set up 2026-10-19)
Seven slices, each adds sourced Tripoli events: 1) 1969–79, 2) 1980–84, 3) 1985–92, 4) 1993–2010, 5) before 1969 (including splitting the combined 1945/1948/1967 riots pin `mk-riots`), 6) deep archive pass, 7) final verification (runs `build-quotes.py`, a browser regression check, and reports before/after counts). Slices 1–3 yielded few pins because Tripoli places are rarely named; most findings sit in `ATLAS_UNPLACED`.
